03

本地服务部署

先按设备选择推理后端；两种方案都由 GLM-OCR SDK 在 8081 端口对外提供识别接口。

当前设备推荐 MLX + GLM-OCR SDK

Chatlog 使用内置运行资产在 Apple Silicon 上自动安装隔离环境与模型，并统一启停 8080 推理服务和 8081 SDK 服务。

  1. 准备：使用 Apple Silicon Mac，并确保首次安装时网络可用。
  2. 启动：点击上方“同步启动模型服务”；Chatlog 自动安装内置运行资产、下载模型并启动进程组。
  3. 配置：选择“本地 GLM-OCR”，服务地址保持 http://127.0.0.1:8081/glmocr/parse。
  4. 验证：健康接口返回 {"status":"ok"} 后即可识别。
无需仓库脚本

安装、启动、停止与异常重启均由 Chatlog 内置运行资产管理；模型状态和操作结果会实时显示在本页。

NVIDIA GPU vLLM + GLM-OCR SDK

Docker Compose 同时启动 CUDA vLLM 推理服务与 GLM-OCR SDK，适用于带 NVIDIA GPU 的 Linux 主机。

  1. 准备：Docker、Compose v2、NVIDIA Container Toolkit，确认 GPU 对容器可见。
  2. 启动：构建并启动 vllm 与 sdk 两个服务。
  3. 配置：同机使用默认 8081 地址；远端部署时填写 SDK 所在主机地址。
  4. 验证：先检查 SDK 健康状态，再在本页保存本地模式。
cd deploy/ocr
docker compose -f docker-compose.vllm.yml up -d --build
curl -fsS http://127.0.0.1:8081/health
docker compose -f docker-compose.vllm.yml logs -f vllm sdk
